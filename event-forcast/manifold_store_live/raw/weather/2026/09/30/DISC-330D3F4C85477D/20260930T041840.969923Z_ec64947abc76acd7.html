Applications & Services

Integrated Dissemination Program (IDP) Applications:

API Web Service
Developer access to critical forecasts, alerts, and observations
AWSPush
Facilitates the transfer of data from the Integrated Dissemination Program (IDP) on-premises data center to Amazon Web Services (AWS) cloud infrastructure
CAP Handler
Receives and transmits Common Alerting Protocol (CAP) messages
CMS
The NWS web Content Management System
CONDUIT
LDM model feed to the university community
EMWIN
Emergency Managers Weather Information Network
Forecast.weather.gov
GMDSS
Global Maritime Distress and Safety System
HF_Fax
Marine Radiofax Charts
IRIS
A suite of applications that assist NWS personnel with providing IDSS
iNWS
Text message and email weather alerts for NWS partners
iSatSS
Converts data from the GOES-R satellite series into formats compatible with NWS software systems
MADIS
Meteorological Assimilation Data Ingest System observations
MAG
NCEP model analyses and guidance imagery
MRMS
Multi-Radar Multi-Sensor (MRMS) data
NGITWS
Oversees the ingestion and dissemination of data
NOMADS
Access NCEP model guidance via grib filter, https download, or openDAP
NWWS-OI
NOAA Weather Wire Service
OWP
Post-processing operations of the Office of Water Prediction (OWP)
Ra4-gifs
WMO Region 4 related weather information in BUFR, GRIB, and alpha-numeric text
Radar.weather.gov
Enhanced radar imagery on an interactive display or standard images for low bandwidth users
SPADES
Processes Level 1 space weather remote sensing data from GOES-R satellite series into Level 2 products
Spot Forecast
NWS core partner incident and decision support request portal
TGFTP
NWSTG FTP server for users to access products and observational data via FTP or HTTPS
Tsunami.gov
Weather.gov


NWS Telecommunications Gateway (NWSTG) Applications:

EDIS
NWS Email Data Input System
FTPMail
Gateway FTPmail service for obtaining observations, facisimile charts, and other forecast products
FTPPush
Outbound FTP to NWS partners without dedicated sockets
FTPS-In
Allows trusted partners to upload data to NWS via FTPS
FTPS-Out
Allows trusted partners to download data from NWS via FTPS
NWSTG LDM
The central NWSTG switching system to distribute bulletins and data products to partners
Radar2
Ingests, processes, and disseminates Radar Level II Data
Radar3
Ingests, processes, and disseminates Radar Level III Data
Sockets
Dedicated constant stream of dataflow to/from core customers


Cloud Applications:

GIS
NWS GIS web services
HydroVIS
Hydrologic Visualization and Inundation Services
NWPS
National Water Prediction Service
Air Quality
National and local ozone, smoke, and dust forecasts
DAT
Damage Assessment Tookit
Digital.weather.gov
An interactive display of the National Digital Forecast Database (NDFD). Legacy display also available.
Map Viewer
GIS Map Viewer
GISC Washington
U.S. contribution to WMO Global Information System Center
NWSChat 2.0
Instant messaging used for communcation between NWS personnel and NWS partners
