MADIS Sample Data

Current data are available for all of the publicly-available datasets. These are made available for anyone who wants to download the software and some data, then try out the system before requesting real-time or archived data from MADIS. The files have been "gzipped" to save on download time. Each hour of compressed data is roughly 60 GB. After uncompressing an hour could be several GB. You might only want to get one or two hours, or just the dataset of interest.

The data can be obtained via https at madis-data.ncep.noaa.gov. Go to the following directories and get the files of interest. The data files are named yyyymmdd_hhmm.gz (yyyymmdd = year, month, day & hhmm = hour, minute). The files should be placed into MADIS data directories on your system (see the section on setting up the run environment in the INSTALL.unix or INSTALL.windows file), then unzipped using the gunzip (or gzip -d) command (for Unix/Linux) or for Windows users, use any standard unzipping utility.
