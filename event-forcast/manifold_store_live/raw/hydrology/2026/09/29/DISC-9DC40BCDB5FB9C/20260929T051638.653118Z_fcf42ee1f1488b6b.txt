# Water Data APIs

> Documentation and machine-readable indexes for the USGS water data APIs, which publish streamflow, groundwater, water-quality, and imagery observations for the United States.

Every link below is a document this site publishes or an API this site documents. Documentation pages also exist as plain markdown at the same URL with "index.html.md" appended, and those are the URLs listed here where they exist.

Retrieve data from the endpoints under "API endpoints" rather than by fetching these pages. Requests are rate limited; register a free API key on the signup page and send it as the api_key query parameter or the X-Api-Key request header.
